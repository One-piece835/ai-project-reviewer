# AI Project Reviewer

AI-powered project review system that analyzes GitHub repositories and provides detailed feedback on:

- Code Quality
- Project Structure
- Maintainability
- Scalability
- Documentation
- Resume Value

## Tech Stack

- Django
- Django REST Framework
- GitHub API
- Gemini API

## Features

- Analyze public GitHub repositories
- Detect technologies used
- Generate AI-powered review reports
- Suggest improvements
